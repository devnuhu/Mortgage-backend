ROLLBACK PROCEDURE (If needed)
================================================================================

If after migration you discover issues and need to revert:

OPTION 1 - Restore from backup (cleanest):
  1. In SSMS: Right-click MMGTDB2A → Tasks → Restore → Database
  2. Select the pre-migration backup
  3. Confirm restore (will lose any changes after migration)
  4. Wait for restore to complete

OPTION 2 - Manual cleanup (if no backup):
  1. Open MIGRATION_SCRIPTS_COMPLETE.sql or create script with:
	 USE MMGTDB2A;
	 ALTER TABLE Applications NOCHECK CONSTRAINT ALL;
	 ... (disable more)
	 DELETE FROM ApplicationDocuments;
	 DELETE FROM ApplicationReviewHistory;
	 DELETE FROM Applications;
	 DELETE FROM Users;
	 DELETE FROM PMICompanies;
	 ALTER TABLE Applications WITH CHECK CHECK CONSTRAINT ALL;
	 ... (re-enable more)
  2. This returns to pre-migration state (reference data intact)

Do NOT keep using pre-migration connection strings - they'll fail without data.

KNOWN LIMITATIONS & NOTES
================================================================================

1. LEGACY DOCUMENTS:
   - All ApplicationDocuments are marked as IsLegacy=1
   - Original document type stored in LegacyDocumentType field
   - All documents default to first active DocumentType
   - Future documents will use new DocumentType system

2. REVIEW STATUS:
   - All migrated ApplicationDocuments have ReviewStatus='pending'
   - Review workflow will process these as new for reviewers
   - Use this to distinguish legacy from new documents

3. FILE STORAGE:
   - All Applications set to DocumentStorageType='FileSystem'
   - FileContent column remains NULL (use FilePath for document access)
   - Actual files should exist at FilePath locations

4. MANDATORY DOCUMENTS:
   - All Applications set to MandatoryDocumentsComplete=0
   - System may indicate these need document completion
   - Adjust if business logic requires

5. COLUMN MAPPINGS NOT IN SOURCE:
   The following columns have defaults and may need business adjustment:
   - Applications.MandatoryDocumentsComplete (0)
   - Applications.CompletedAt (set for approved/rejected only)
   - Applications.PhoneNumber (NULL)
   - ApplicationDocuments.ReviewedBy (NULL)
   - ApplicationDocuments.ReviewedAt (NULL)
   - ApplicationDocuments.ReviewComments (NULL)
   - ApplicationDocuments.FileContent (NULL)
